# Superseded specification

This directory is retained as historical design evidence. It is superseded for implementation and compatibility decisions by:

- `docs/contracts/aether-newapi-v1.json`
- `docs/contracts/aether-newapi-v1.schema.json`
- `docs/contracts/aether-newapi-v1.examples.json`

The active implementation plan keeps New API as the financial authority, enables only `direct_channel`, and requires AETHER to reuse its existing Provider, Pool, Routing Profile, proxy, and settlement paths. Historical requirements in this directory must not override that boundary.
